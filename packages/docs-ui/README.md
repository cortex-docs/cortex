# @cortex/docs-ui

`@cortex/docs-ui` is the documentation runtime for Cortex Docs projects.

The [`@cortex/cli`](https://www.npmjs.com/package/@cortex/cli) package installs and starts this package. Direct use is not supported.

Read the [Cortex Docs repository](https://github.com/cortex-docs/cortex) for usage and contribution information.
