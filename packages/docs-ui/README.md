# @cortex-docs/docs-ui

`@cortex-docs/docs-ui` is the documentation runtime for Cortex Docs projects.

The [`@cortex-docs/cli`](https://www.npmjs.com/package/@cortex-docs/cli) package installs this package. Use `cortex docs serve` for a local preview with file watching.

Use `cortex docs build` to export static HTML, CSS, JavaScript, and documentation data. The deployed site needs no Node.js server.

Direct use of this package is not supported.

Read the [Cortex Docs repository](https://github.com/cortex-docs/cortex) for usage and contribution information.
