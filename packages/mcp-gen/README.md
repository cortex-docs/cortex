# @cortex-docs/mcp-gen

`@cortex-docs/mcp-gen` creates Model Context Protocol servers from API specifications and project documentation.

Most users install [`@cortex-docs/cli`](https://www.npmjs.com/package/@cortex-docs/cli) instead of this package.

Read the [Cortex Docs repository](https://github.com/cortex-docs/cortex) for usage and contribution information.
