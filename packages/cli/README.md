# @cortex/cli

`@cortex/cli` is the command-line interface for Cortex Docs.

Install the CLI:

```bash
npm install --global @cortex/cli
```

Create a project:

```bash
cortex init my-api --open-api ./openapi.yaml
cd my-api
cortex generate
cortex docs serve
```

Read the [Cortex Docs repository](https://github.com/cortex-docs/cortex) for the complete documentation.
