# Support

Use the [GitHub issue tracker](https://github.com/cortex-docs/cortex/issues) for reproducible bugs and feature requests.

Before you open an issue:

1. Upgrade to the latest release.
2. Run `cortex validate`.
3. Remove credentials and private data from the example.
4. Search existing issues.

Include the Cortex Docs version, Node.js version, operating system, command, and complete error message.

For security problems, follow [SECURITY.md](SECURITY.md). Do not post sensitive reports in a public issue.
