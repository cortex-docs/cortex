# Code of Conduct

## Our standard

We want the Cortex Docs community to be safe, useful, and welcoming.

Be respectful. Discuss the work, not the person. Give clear feedback and accept that other people can have different experience or constraints.

The following behavior is not acceptable:

- Harassment, threats, or discrimination
- Sexualized language or unwanted attention
- Publishing private information without permission
- Deliberate disruption of community work
- Personal attacks or repeated hostile behavior

## Enforcement

Maintainers can edit or remove content and can limit participation when behavior does not meet this standard. Enforcement decisions will consider the context, severity, and effect of the behavior.

To make a private report, use the repository's [private vulnerability reporting form](https://github.com/cortex-docs/cortex/security/advisories/new). State that the report concerns community conduct. Maintainers will protect the reporter's privacy as far as possible.

This code applies in repository spaces and when a person officially represents the project.
